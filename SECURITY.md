# Security Policy

## Supported Releases

Security reports are handled for the latest normal GitHub release of VyoraXR and VyoraTV.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately through GitHub's private vulnerability reporting or another private channel to the repository maintainer. Do not open a public issue for an undisclosed vulnerability.

Include:

- The affected app and version.
- The platform and relevant configuration, without private credentials.
- Clear reproduction steps.
- The possible impact.

Please do not include passwords, API keys, private media, personal data or publicly reachable private server addresses.

## Response

Reports will be reviewed as soon as practical. A fix or mitigation may be published in a future release, depending on severity and reproducibility.
