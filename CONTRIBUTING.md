# Contributing to Vyora

The public Vyora repository contains release APKs, documentation and store assets. The application source code is proprietary and is not published here.

## Useful Contributions

- Reproducible bug reports.
- UI and accessibility feedback for Quest or Android TV.
- Documentation improvements.
- Translation suggestions.
- Suggestions for supported media sources and integrations.

## Before Opening an Issue

1. Check the README and existing issues.
2. Confirm the problem on the latest normal GitHub release.
3. Include the platform, app version and a short reproduction path.
4. Remove passwords, API keys, private URLs, private media and personal device details.

## Pull Requests

Documentation and template improvements are welcome. Please keep changes focused and explain what was changed and how it was checked.
